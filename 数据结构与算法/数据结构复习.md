# 数据结构复习笔记

## 第一章：数据结构与算法

### 时间复杂度

算法效率的度量主要通过时间复杂度和空间复杂度描述

常用排序：$$O(1) < O(\log_2 n) < O(n) < O(n \log_2 n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

计算规则：

- 加法规则（顺序执行）：取最大项，$O(\max(f(n), g(n)))$
- 乘法规则（嵌套循环）：$O(f(n) \times g(n))$
- 递归算法：通常为递归次数 $\times$ 每次递归的时间

对数阶：$O(\log_2 n)$

```python
i = 1;
while(i <= n)
    i = i * 2;
```

### 算法特性

有穷性，确定性，可行性，输入，输出

### 逻辑结构与存储结构

逻辑结构：

- 线性结构：线性表、栈、队列、串（一对一）
- 树形结构：树、二叉树（一对多）
- 图形结构：有向图、无向图（多对多）
- 集合：无关系

存储结构（物理结构）：

- 顺序存储：物理相邻（数组）
- 链式存储：指针链接（链表）
- 索引存储：建立索引表
- 散列存储：Hash计算地址

## 第二章：线性表

### 顺序表地址计算

假设起始地址为 $LOC(A)$，每个元素占 $L$ 个存储单元，则第 $i$ 个元素（下标 $i-1$）的地址为：

$$LOC(a_i) = LOC(A) + (i-1) \times L$$

### 顺序表 vs 链表

| **特性**      | **顺序表**                       | **链表**                 |
| ------------- | -------------------------------- | ------------------------ |
| **存取方式**  | 随机存取 $O(1)$                  | 顺序存取 $O(n)$          |
| **逻辑/物理** | 逻辑相邻，物理也相邻             | 逻辑相邻，物理不一定相邻 |
| **插入/删除** | 需要移动大量元素，平均移动 $n/2$ | 修改指针即可，无需移动   |
| **空间分配**  | 静态/动态数组，易溢出或浪费      | 动态分配，利用率高       |
| **适用场景**  | 频繁查询，很少插入删除           | 频繁插入删除，查询较少   |

### 顺序表插入删除

插入：

```c
// 从最后一个元素开始，倒着往后移
for(int j = L.length; j >= i; j--)
    L.data[j] = L.data[j-1]; 
L.data[i-1] = e; // 放入新元素
L.length++;      // 长度加1
```

删除：

```c
e = L.data[i-1]; // 保存被删元素
// 从被删位置的下一个开始，顺着往前移
for(int j = i; j < L.length; j++)
    L.data[j-1] = L.data[j];
L.length--;      // 长度减1
```

### 链表

头结点：为了统一第一个结点的操作，通常在链表头部附加一个节点，称为头结点
头指针（L）：指向链表第一个节点的指针

判空条件：

- 单链表（带头结点）：$L \rightarrow next == NULL$
- 循环单链表（带头结点）：$L \rightarrow next == L$

单链表定义：

```c
typedef struct LNode {
    ElemType data;      // 数据域
    struct LNode *next; // 指针域
} LNode, *LinkList;
```

双链表定义：

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next; // 两个指针
} DNode, *DLinkList;
```



### 单链表插入删除

插入：

1. `s->next = p->next;` 
2. `p->next = s;`

删除：

1. `q = p->next;`
2. `p->next = q->next;` 
3. `free(q);`

### 双链表插入删除

插入：

1. `s->next = p->next;` 
2. `p->next->prior = s;` 
3. `s->prior = p;` 
4. `p->next = s;` 

删除：

1. `p->next = q->next;`
2. `q->next->prior = p;` 
3. `free(q);`

## 第三章：栈和队列

### 栈

定义：只允许在一段进行插入或删除的线性表（LIFO，后进先出）

$n$ 个元素进栈，合法的出栈序列个数（卡特兰数）为：$$\frac{1}{n+1} C_{2n}^n = \frac{1}{n+1} \times \frac{(2n)!}{n! \times n!}$$

共享栈：两个栈共享同一维数组，栈底在两端，向中间延伸。此时栈满条件：$Top_1 + 1 == Top_2$

### 队列

定义：一端插入，另一端删除（FIFO，先进先出）

循环队列（解决“假溢出”）：

假设数组大小为 $MaxSize$，队头指针 $F$，队尾指针 $R$

- 队空条件：$R == F$
- 队满条件：$(R + 1) \% MaxSize == F$ （牺牲一个单元）
- 队列长度：$(R - F + MaxSize) \% MaxSize$
- 入队操作：$R = (R + 1) \% MaxSize$
- 出队操作：$F = (F + 1) \% MaxSize$

## 第四章：串与数组

### KMP 算法

- 核心：利用已经匹配的信息，主指针 $i$ 不回溯，只回溯模式串指针 $j$
- Next 数组计算：
  - $next[1] = 0, next[2] = 1$
  - 后续值取决于前缀和后缀的最长公共元素长度 $+ 1$

基于python的实现（next数组不太一样）

```python
def build_next(pattern):
    m = len(pattern)
    nxt = [0] * m
    prefix_len = 0 
    for i in range(1, m):
        while prefix_len > 0 and pattern[i] != pattern[prefix_len]:
            prefix_len = nxt[prefix_len - 1]
        if pattern[i] == pattern[prefix_len]:
            prefix_len += 1
        nxt[i] = prefix_len
    return nxt

def kmp_search(text, pattern):
    n = len(text)
    m = len(pattern)
    nxt = build_next(pattern)
    j = 0 #模式串指针
    for i in range(n): # i 为主串指针
        while j > 0 and text[i] != pattern[j]:
            j = nxt[j - 1]
        if text[i] == pattern[j]:
            j += 1
        if j == m:
            j = nxt[j - 1] 
            return i - m + 1
    return -1 
# 主串
text_str = "ababaababaa"
# 模式串
pat_str = "ababaa"
kmp_search(text_str, pat_str)
```

### 矩阵压缩存储

对称矩阵则只存下三角，此时下标 $k$ 与 $i, j$ 的关系（$i \ge j$，下标从 0 开始）：

$$k = \frac{i(i+1)}{2} + j$$

如果给出是上三角（即`i<j`）则交换`ij`即可

三角矩阵：类似对称矩阵，尾部多存一个常数（填充三角以外的数）

稀疏矩阵：
当矩阵中非零元素极少且分布无规律时，称为稀疏矩阵
为了节省空间，只存储非零元素的三元组 `(行标 i, 列标 j, 值 v)`
还需额外存储`（总行数，总列数，非零元素总数）`

三元组的转置算法：

- 朴素转置算法：按列号（0 到 n-1）依次去扫描三元组表，找到对应的元素并搬运
  复杂度$$O(n \times t)$$（$n$ 是列数，$t$ 是非零元个数）
  缺点：如果非零元很多（$t \approx n^2$），复杂度退化为 $O(n^3)$
- 快速转置算法：一次遍历算出每一列有多少个元素，直接定好它们在目标数组中的位置
  辅助数组：
  `num[col]`：统计 $M$ 中第 `col` 列的非零元个数
  `cpot[col]`：预测 $M$ 中第 `col` 列的第一个非零元在 $T$ 的三元组表中的起始下标
  递推公式：
  $$cpot[0] = 0$$
  $$cpot[col] = cpot[col-1] + num[col-1]$$
  复杂度$$O(n + t)$$（非常快，仅遍历列数和非零元数）

## 第五章：树与二叉树

### 二叉树性质

- 叶子与度：对任何非空二叉树，$n_0 = n_2 + 1$ （叶子数 = 度为2的节点数 + 1）
- 第 $i$ 层最大结点数：$2^{i-1}$
- 高度为 $h$ 的最大结点数：$2^h - 1$
- 完全二叉树编号（结点 $i$）：
  - 左孩子：$2i$ （若 $2i > n$ 则无左孩子）
  - 右孩子：$2i + 1$
  - 双亲：$\lfloor i/2 \rfloor$

### 二叉树遍历

- 先序：根 $\rightarrow$ 左 $\rightarrow$ 右
- 中序：左 $\rightarrow$ 根 $\rightarrow$ 右
- 后序：左 $\rightarrow$ 右 $\rightarrow$ 根
- 构造二叉树一定要有中序

### 哈夫曼树

- 定义：带权路径长度 (WPL) 最小的二叉树

- WPL计算：

  $$WPL = \sum_{i=1}^n (w_i \times l_i)$$

  其中 $w_i$ 是权值，$l_i$ 是路径长度（深度-1）

- 构造方法：每次选取权值最小的两棵树合并，新权值为两者之和，删去旧权值。直到集合中只剩下一个权值
  在此构造方法下，WPL计算可以简化为：所有合并后的值相加。或者说是，所有非叶子结点的权值之和

- 哈夫曼编码：前缀编码，任一字符编码都不是另一字符编码的前缀

### 线索二叉树

利用二叉链表中的空指针域，存放指向结点在某种遍历次序下的前驱和后继结点的指针（这种指针称为“线索”）
节省空间同时提高查找效率

对于 $n$ 个结点的二叉树：

- 总指针数：$2n$
- 有效指针数（指向孩子）：$n-1$
- 空指针数（可做线索）：$2n - (n-1) = n + 1$

存储结构：在结点结构中增加两个标志位 `ltag` 和 `rtag`，置1时表示前驱/后继

操作：遍历一次二叉树，在遍历过程中修改空指针

需要一个全局变量 pre 指向当前访问结点 p 的前驱

关键操作（以中序为例）：

1. 若 `p->lchild` 为空，则 `p->lchild = pre`; `p->ltag = 1` (建立前驱线索)
2. 若 `pre` 非空且 `pre->rchild` 为空，则 `pre->rchild = p`; `pre->rtag = 1` (建立后继线索)
3. 更新 `pre = p`

找后继/前驱的规律：

| 线索树类型     | 找后继难度                                                | 找前驱难度                                                |
| -------------- | --------------------------------------------------------- | --------------------------------------------------------- |
| 中序线索二叉树 | 容易 (若 `rtag==1` 直接取；若 `0` 则找右子树最左下的结点) | 容易 (若 `ltag==1` 直接取；若 `0` 则找左子树最右下的结点) |
| 先序线索二叉树 | 容易 (左孩子 $\rightarrow$ 右孩子)                        | 困难 (需要父指针，因为不知是从左还是右下来的)             |
| 后序线索二叉树 | 困难 (需要父指针，因为根是最后访问的)                     | 容易 (右孩子 $\rightarrow$ 左孩子)                        |

先序线索化中，若 `lchild` 为空且被线索化指向了前驱（祖先），必须防止回回头（死循环），需要判断 `ltag==0` 才递归左子树
最后一个结点的 `rchild` 通常置为 NULL 或指向头结点

## 第六章：图

### 图的存储

- 邻接矩阵：二维数组 $A[i][j]$。
  - 空间复杂度：$O(n^2)$
  - 适合：稠密图
  - 计算度：行之和（出度），列之和（入度）
- 邻接表：顶点表 + 边表（链表） 
  - 空间复杂度：$O(n+e)$ （有向图）或 $O(n+2e)$ （无向图）
  - 适合：稀疏图

### 最小生成树 (MST)

Prim 算法：
- 关注点：顶点
- 策略：从集合中选一个顶点，找连接未访问顶点的最小边
- 复杂度：$O(n^2)$，适合稠密图
- 步骤：
  1. 初始化：visited集合只包含起点
  2. 选边：寻找一个端点在visited中，另一个端点在visited外的最小权值边
  3. 加入：将该边的另一端点加入visited
  4. 重复：直到所有顶点都在visited中
  
- 代码

  ```python
  def prim(graph, start_node):
      mst_cost = 0
      visited = {start_node}
      edges = []
      # 初始边加入
      for to, weight in graph[start_node].items():
          edges.append((weight, start_node, to))
      # 循环直到覆盖所有点
      while len(visited) < len(graph):
          # 找到最小边
          edges.sort()
          for i, (w, u, v) in enumerate(edges):
              if v not in visited:
                  visited.add(v)
                  mst_cost += w
                  # 将新点的边加入待选集合
                  for next_node, next_w in graph[v].items():
                      if next_node not in visited:
                          edges.append((next_w, v, next_node))
                  edges.pop(i)
                  break
              else:
                  edges.pop(i)   
      return mst_cost
  ```

Kruskal 算法：
- 关注点：边
- 策略：按权值排序，从小到大选边，若不构成回路则加入
- 复杂度：$O(e \log e)$，适合稀疏图
- 核心步骤

  1. 排序：将所有边按权值从小到大排序

  2. 选边：依次取出最小的边 (u, v)

  3. 判环：检查 u和v是否在同一个连通分量中（使用并查集）

     若不在：加入该边，合并连通分量

     若在：丢弃该边

  4. 终止：直到选中 n-1 条边
- 代码：

  ```python
  class UnionFind:
      def __init__(self, nodes):
          self.parent = {n: n for n in nodes}
      def find(self, x):
          if self.parent[x] != x:
              self.parent[x] = self.find(self.parent[x])
          return self.parent[x]
      def union(self, x, y):
          rootX = self.find(x)
          rootY = self.find(y)
          if rootX != rootY:
              self.parent[rootX] = rootY
              return True
          return False
  def kruskal(nodes, edges):
      mst_cost = 0
      uf = UnionFind(nodes)
      mst_edges = []
      edges.sort() # 按权值排序
      for w, u, v in edges:
          if uf.union(u, v):  # 判环与合并
              mst_cost += w
              mst_edges.append((u, v))
              
      return mst_cost, mst_edges
  ```

### 最短路径

Dijkstra：
- 求解单源最短路径
- 贪心策略，每次确定一个距离最近的顶点，并以它为跳板松弛其他顶点
- 不支持负权边
- 复杂度：$O(n^2)$
- 核心步骤

  1. 初始：dist[start]=0，其余为 $$\infty$$，visited为空
  2. 选点：在未访问集合中，选取 dist 最小的顶点u
  3. 标记：将 u 加入visited
  4. 松弛：遍历 u 的邻居v，若经 u 到 v 更近，则更新dist[v]
  5. 重复：直到所有点被访问
- 代码：

  ```python
  def dijkstra(graph, start):
      # 初始化
      dist = {node: float('inf') for node in graph}
      dist[start] = 0
      visited = set()
      while len(visited) < len(graph):
          # 选点
          min_node = None
          min_val = float('inf')
          for node in graph:
              if node not in visited and dist[node] < min_val:
                  min_val = dist[node]
                  min_node = node
          if min_node is None: break
          visited.add(min_node) # 标记
          for neighbor, weight in graph[min_node].items():# 松弛
              if neighbor not in visited:
                  new_dist = dist[min_node] + weight
                  if new_dist < dist[neighbor]:
                      dist[neighbor] = new_dist
      return dist
  ```

Floyd：
- 求解多源最短路径（任意两点间的最短路径）
- 动态规划思想
- 支持负权边，但不支持负权环
- 时间复杂度：$$O(n^3)$$，空间复杂度：$$O(n^2)$$
- 核心步骤

  1. 初始：构建邻接矩阵 $$matrix$$，$$matrix[i][j]$$表示$$i$$到$$j$$的直达距离（无边为$$\infty$$，自环为 0）
  2. 迭代：引入中转点 $$k$$（从 0 到 $$n-1$$），尝试优化任意两点 $$i$$和$$j$$ 的路径状态转移方程：$$dist[i][j] = \min(dist[i][j], \ dist[i][k] + dist[k][j])$$
  3. 判断：若经过 $$k$$ 中转的距离比原距离更短，则更新
  4. 重复：$$k$$遍历完所有顶点后，算法结束
- 代码

  ```python
  def floyd(graph):
      n = len(graph) # graph 是邻接矩阵，二维列表
      dist = [row[:] for row in graph] # 以防修改原数据
      # k：遍历中转点
      for k in range(n):
          # i：遍历起点
          for i in range(n):
              # j：遍历终点
              for j in range(n):
                  # 核心状态转移
                  if dist[i][k] + dist[k][j] < dist[i][j]:
                      dist[i][j] = dist[i][k] + dist[k][j]
      return dist
  ```

### 拓扑排序

在一个有向无环图中，将所有顶点排成一个线性序列

满足条件：若存在边 $$A \to B$$，则在序列中 $$A$$必须排在$$B$$ 前面

用途：解决工程进度的先后顺序问题，判断图中是否有环

复杂度：$$O(n+e)$$

步骤

1. 选择：在图中找一个入度为0的顶点（没有前驱）
2. 输出：输出该顶点
3. 删除：删除该顶点及其所有出边（即将它指向的顶点的入度减 1）
4. 重复：直到所有顶点输出，或图中不存在入度为0的顶点（说明有环）

```python
from collections import deque

def topological_sort(graph_adj, num_nodes):
    """
    graph_adj: 邻接表 {u: [v1, v2, ...]}
    num_nodes: 顶点数量
    """
    # 计算所有节点入度
    in_degree = {i: 0 for i in range(num_nodes)}
    for u in graph_adj:
        for v in graph_adj[u]:
            in_degree[v] += 1  
    # 将入度为0的节点加入队列
    queue = deque([u for u in in_degree if in_degree[u] == 0])
    topo_order = []
    while queue:
        u = queue.popleft()
        topo_order.append(u)
        # 遍历邻居，减少入度
        if u in graph_adj:
            for v in graph_adj[u]:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)
    # 判断是否有环 (输出数量是否等于节点总数)
    if len(topo_order) == num_nodes:
        return topo_order
    else:
        return [] # 存在环
```

### 关键路径

关键路径：从源点到汇点路径长度最长的路径

关键活动：关键路径上的边

意义：关键路径的长度决定了整个工程的最短完成时间

特点：关键活动没有任何机动时间

四个核心参数

1. 事件最早发生时间 $$ve(k)$$：从源点到顶点 $$k$$ 的最大路径长度。公式：$$ve(j) = \max(ve(i) + weight(i, j))$$ （前推法，取大）
2. 事件最迟发生时间 $$vl(k)$$：在不推迟整个工程完成的前提下，顶点 $$k$$允许发生的最晚时间
   公式：$$vl(i) = \min(vl(j) - weight(i, j))$$（后推法，取小）
3. 活动最早开始时间 $$e(i)$$：边的起点事件的最早发生时间
4. 活动最迟开始时间 $$l(i)$$：边的终点事件的最迟发生时间 - 边权值

求解步骤

1. 拓扑排序：得到顶点的线性序列
2. 求 ve：按拓扑序列，从前往后计算每个顶点的 $$ve$$（初始为0，遇多条边取max）
3. 求 vl：按逆拓扑序列，从后往前计算每个顶点的 $$vl$$（初始为汇点的 $$ve$$，遇多条边取min）
4. 找关键活动：对于每条边 $$<u, v>$$，若 $$ve(u) == vl(v) - weight(u, v)$$，则为关键活动

```python
def critical_path(num_nodes, edges):
    # 构建邻接表
    graph = {i: [] for i in range(num_nodes)}
    for u, v, w in edges:
        graph[u].append((v, w))
        
    # 1. 获取拓扑序列 (使用上面的逻辑，此处简化直接手动指定或假设已知)
    # 实际应调用 topological_sort，这里假设返回了 topo_order
    # 假设 topo_order = [0, 1, 2, 3, ...] 
    topo_order = list(range(num_nodes)) # 仅作演示占位
    
    # 2. 计算 ve (最早发生时间)
    ve = {node: 0 for node in range(num_nodes)}
    for u in topo_order:
        for v, w in graph[u]:
            if ve[u] + w > ve[v]:
                ve[v] = ve[u] + w
                
    # 3. 计算 vl (最迟发生时间)
    # 初始化为汇点的 ve 值
    max_time = max(ve.values())
    vl = {node: max_time for node in range(num_nodes)}
    
    # 逆序遍历
    for u in reversed(topo_order):
        for v, w in graph[u]:
            if vl[v] - w < vl[u]:
                vl[u] = vl[v] - w
                
    # 4. 找出关键路径 (Slack = 0 的边)
    critical_edges = []
    for u, v, w in edges:
        e = ve[u]          # 活动最早开始
        l = vl[v] - w      # 活动最迟开始
        if e == l:
            critical_edges.append((u, v, w))
            
    return max_time, critical_edges
```

## 第七章：查找

### 折半查找/二分查找

条件：顺序存储 + 有序

公式：$mid = \lfloor (low + high) / 2 \rfloor$

ASL (平均查找长度)：$\approx \log_2(n+1) - 1$

判定树：一棵平衡二叉排序树

代码：（难点是边界条件的判定）

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1  # 注意1：这里是 n-1
    while low <= high:#这里必须是 <=，因为 low==high 时还有一个元素没看
        # 找中间点
        mid = (low + high) // 2 
        if arr[mid] == target:
            return mid  # 找到
        elif arr[mid] > target:
            high = mid - 1  # 猜大了，往左缩，mid已经看过了，所以-1
        else:
            low = mid + 1   # 猜小了，往右缩，mid已经看过了，所以+1
    return -1  # 没找到
```

### 散列查找/哈希表

构造函数：除留余数法 $H(key) = key \% p$ （$p$ 为不大于表长的最大质数）

冲突处理：
1. 开放定址法：
   - 线性探测：$d_i = (H(key) + i) \% m$
   - 平方探测：$d_i = (H(key) \pm i^2) \% m$
2. 拉链法：同义词链成链表

装填因子 $\alpha$：$\alpha = n / m$ （记录数/表长）
$\alpha$ 越大，冲突概率越大

ASL = （所有元素查找次数之和）/ 元素个数

### 快速排序

核心：选定 pivot，左边比它小，右边比它大

最好情况：每次都平分

最坏情况：本身有序（退化为冒泡）

```python
def quick_sort(arr):
    # 终止条件：数组为空或只有一个元素
    if len(arr) <= 1:
        return arr
    # 选基准：第一个元素
    pivot = arr[0]
    # 分区：利用列表推导式，将数组分成三部分
    left = [x for x in arr[1:] if x <= pivot]  # 比基准小的
    right = [x for x in arr[1:] if x > pivot]  # 比基准大的
    # 递归并合并：排好左边 + 基准 + 排好右边 
    return quick_sort(left) + [pivot] + quick_sort(right)
data = [5, 3, 8, 4, 2, 7, 1, 10]
print(quick_sort(data)) 
```



### 堆排序

结构：利用完全二叉树

大根堆：父节点 $\ge$ 子节点（`arr[i] >= arr[2*i+1]` 且 `arr[i] >= arr[2*i+2]`）

过程：

1. 建堆：从最后一个非叶子节点开始，倒着调整
2. 排序：把堆顶（最大值）交换到末尾，排除它，然后剩下的重新调整

时间复杂度：**$O(n \log n)$**

空间复杂度**：**$O(1)$

适合 Top K 问题

```python
def heapify(arr, n, i):
    """
    下坠函数
    n: 堆的长度（不是数组总长，是当前还剩多少没排序）
    i: 当前要下坠的节点下标
    """
    largest = i       # 假设爸爸最大
    left = 2 * i + 1  # 左儿子下标
    right = 2 * i + 2 # 右儿子下标
    # 找个最大的出来
    # 如果左儿子存在，且比爸爸大
    if left < n and arr[left] > arr[largest]:
        largest = left
    # 如果右儿子存在，且比刚才找到的还大
    if right < n and arr[right] > arr[largest]:
        largest = right
    # 如果最大的不是爸爸，就要交换
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i] # 交换  
        # 递归
        heapify(arr, n, largest)

def heap_sort(arr):
    n = len(arr)
    # 从最后一个非叶子节点 (n//2 - 1) 开始，倒着走到 0
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    # 从最后一个元素开始，一个个换到前面去
    for i in range(n - 1, 0, -1):
        # 把最大的(堆顶 0)换到最后(i)
        arr[i], arr[0] = arr[0], arr[i]
        # 剩下的元素(长度为 i)重新调整堆
        heapify(arr, i, 0)
    return arr
print(heap_sort([4, 6, 8, 5, 9]))
```

### 归并排序

先切分再合并

只有它在 $O(n \log n)$ 级别还能保持稳定

需要额外的内存空间 $O(n)$ 来暂存数据（空间换时间）

```python
def merge(left, right):#合并两个有序数组
    result = []
    i = 0  # 左队指针
    j = 0  # 右队指针
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result += left[i:]
    result += right[j:]
    return result
def merge_sort(arr):#负责切分和递归
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    # 递归切分左边
    left_half = merge_sort(arr[:mid])
    # 递归切分右边
    right_half = merge_sort(arr[mid:])
    return merge(left_half, right_half)

# 测试
arr = [8, 4, 5, 7, 1, 3, 6, 2]
print(merge_sort(arr))
```

### 基数排序

从低位向高位排

```python
def radix_sort(arr):
    # 找最大数，确定要排几轮 (d)
    max_num = max(arr)
    max_digit = len(str(max_num))
    exp = 1 #exp 是 1, 10, 100... (代表个位、十位、百位)
    for i in range(max_digit):
        buckets = [[] for _ in range(10)]# 准备 10 个空桶
        for num in arr:
            digit = (num // exp) % 10 # 算出当前位的数字
            buckets[digit].append(num)
        arr = []
        for bucket in buckets:
            arr.extend(bucket)
        exp *= 10 # 进位，下一轮
    return arr
arr = [520, 312, 513, 122]
print(radix_sort(arr))
```

### 简单选择

每次选出最小的放前面

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

### 直接插入

将数插入到往前数，第一个比他小的后面

```python
def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        temp = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > temp:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = temp
    return arr
```
