# 数电复习文档

## 课时一 数制与编码

### 进制

二进制（B）
十进制（D）
八进制（O）
十六进制（H）

### 数制转换

二进制转十进制：按权展开法
将每一位乘以对应的2的幂次（整数位为正幂，小数位为负幂）后求和

十进制转二进制： 

1. 整数部分：除2取余法
   不断除以2，直到商为0，余数倒序排列（下为高位，上为低位）
2. 小数部分：乘2取整法
   不断乘以2，取整数部分，直到小数部分为0或达到精度，整数正序排列

二进制与十六进制转换：四位一体法
以小数点为界，整数向左、小数向右每四位一组（不足补0），转换为对应的十六进制数

二进制与八进制转换：三位一体法
原理同上，每三位对应一位八进制数

### 编码

8421 BCD码：用4位二进制数表示1位十进制数（0-9）
注意：`1010`到`1111`在8421BCD码中是非法的

余3码就是从0011（也就是3）开始，依次加一

2421码是把总数小于等于4的以0开头，总数大于4的以1开头

5211码是把小于5的以0开头，大于5的以1开头

## 课时二 逻辑代数

### 异或同或

异或运算 (XOR)：相异出1，相同出0
表达式 F = A ⊕ B
或：F=A’B+AB’

同或运算 (XNOR)：相同出1，相异出0

### 逻辑代数基本规则

反演规则：求反函数
与变或，或变与；1变0，0变1；原变量变反变量，反变量变原变量
注意保持运算优先顺序

对偶规则：求对偶式
与变或，或变与；1变0，0变1
变量形式不变

代入定理
在任何一个包含变量A的逻辑等式中，若以另外一个逻辑式代入式中所有A的位置，则等式成立
简单来讲，就是只要我代替了你这个等式中所有的A，那么代替A后的这个等式也是成立的

### 公式

基本运算律

- 0-1律：$A \cdot 0 = 0, \quad A + 1 = 1$
- 重叠律：$A \cdot A = A, \quad A + A = A$
- 互补律：$A \cdot \bar{A} = 0, \quad A + \bar{A} = 1$
- 分配律：
  - 常规：$A(B+C) = AB + AC$
  - 对偶：$A + BC = (A+B)(A+C)$
- 反演律 (摩根定律)：(拆非号：与变或，或变与)
  - $\overline{A \cdot B} = \bar{A} + \bar{B}$
  - $\overline{A + B} = \bar{A} \cdot \bar{B}$

常用化简公式

- 并项法：$AB + A\bar{B} = A$ (提取公因式，合并相邻项)
- 吸收法：$A + AB = A$ (小范围被大范围吸收)
- 消因子法：$A + \bar{A}B = A + B$ (消去多余的取反因子)
- 消项法 (冗余律)：$AB + \bar{A}C + BC = AB + \bar{A}C$ (消去含互补变量两项之外的第三项)
- 配项法：利用 $A+A=A$ 或 $A+\bar{A}=1$ 增加项以辅助化简

### 最小项

定义：n个变量的逻辑与项，包含全部n个变量，每个变量以原变量或反变量形式出现一次

性质：任意输入组合下，只有一个最小项值为1；全体最小项之和为1

编号：将最小项中原变量记为1，反变量记为0，得出的二进制数转为十进制即为编号m

## 课时三 卡诺图

### 卡诺图结构

排列规则：按格雷码顺序排列（相邻方格只变1位）

相邻性：几何相邻（上下左右）和相对相邻（首尾折叠）的方格逻辑上相邻

### 卡诺图化简步骤

1. 将函数化为最小项之和，在卡诺图对应位置填1
2. 画卡诺圈： 
   圈内1的个数必须是2的n次方（1, 2, 4, 8...）
   圈越大越好，个数越少越好
   每个圈必须包含至少一个新选取的1
3. 写出表达式：
   保留圈内不变的变量，消去变化的变量

圈住$2^{n}$个格子，能消去n个变量

### 无关项

定义：逻辑函数中某些输入组合不出现或对输出无影响的项，用×或d表示

应用：无关项可当做1（圈入）或当做0（不圈入），灵活利用以获得更大的卡诺圈

判别：当逻辑表达式化简为 F=A+A' 或 F=A·A' 形式时，存在竞争冒险

## 课时五 常用组合逻辑器件

### 编码器

编码器的功能就是将输入的每一个高、低电平信号编成一个对应的二进制代码
其本质就是赋予二进制代码特定含义的过程，一般分为普通编码器和优先编码器两类

普通和优先的区别在于普通编码器要求只输入一个有效编码信号，而优先编码器允许多个有效编码信号的输入，但是只会从优先级最高的那个开始，比如3-8线优先编码器，则最先从I7开始编码

逻辑表达式（以8-3线普通编码器为例）：

$$Y_2 = I_4 + I_5 + I_6 + I_7$$

$$Y_1 = I_2 + I_3 + I_6 + I_7$$

$$Y_0 = I_1 + I_3 + I_5 + I_7$$

### 译码器 (74LS138)

功能：3线-8线译码器

输入：3个地址端 A2, A1, A0；3个使能端（G1为1，其余为0）

输出：8个输出端 Y0-Y7（低电平有效）

逻辑表达式：

令使能信号 $E = G_1 \cdot \overline{G_{2A}} \cdot \overline{G_{2B}}$，且 $m_i$ 为地址输入的最小项，则：$Y_i = \overline{E \cdot m_i}$

特点：当使能有效时，对应地址的输出端为0，其余为1

扩展应用：利用译码器实现逻辑函数
将函数化为最小项之和，利用输出端的低电平信号接入与非门实现

### 数据选择器

8选1数据选择器 (74LS151)
输入：8个数据端 D0-D7；3个地址端 A2, A1, A0；使能端S
输出：1个输出端 Y（及反码 W）
扩展应用：实现3变量或4变量逻辑函数
将变量接在地址端，根据真值表设定数据端的电平（0、1或剩余变量）
逻辑表达式：$Y = \overline{S} \cdot \sum_{i=0}^{7} m_i \cdot D_i$
展开即：$Y = \overline{S} (\overline{A}_2\overline{A}_1\overline{A}_0 D_0 + \dots + A_2A_1A_0 D_7)$

双4选1数据选择器（74LS153）
4个数据端+4个数据端，2个地址端，两个使能端
共用地址但是分别选两组不同的数据
逻辑表达式（其中一组）：$$1Y = 1\overline{E} \cdot (m_0 \cdot 1D_0 + m_1 \cdot 1D_1 + m_2 \cdot 1D_2 + m_3 \cdot 1D_3)$$

### 加法器

半加器：只管两个1位二进制数相加，不考虑低位有没有进位
输入：加数 A、加数 B
输出：和 S、进位 C
公式：
$S = A \oplus B$ （异或：1+0=1，1+1=0）
$C = A \cdot B$（与：只有1+1=2时才产生进位）

全加器：不仅两个数相加，还要加上低位送来的进位
输入：加数 A、加数 B、低位进位 $C_{in}$
输出：和 S、向高位的进位 $C_{out}$
公式：
$S = A \oplus B \oplus C_{in}$ （三个数异或。口诀：输入中有奇数个1，S就是1）
$C_{out} = (A \oplus B ) C_{in} + AB$

### 多位加法器

串行进位：低位的 $C_{out}$ 接到高位的 $C_{in}$
缺点：时延

超前进位：用逻辑电路计算进位，不需要等前一位计算结果
逻辑表达式：定义生成信号 $G_i = A_i B_i$，传播信号 $P_i = A_i + B_i$
则第 $i+1$ 位的进位为：$$C_{i+1} = G_i + P_i C_i$$
通过迭代带入，可得各级进位只与初始进位 $C_0$ 和输入 $A, B$ 有关（如 $C_2 = G_1 + P_1G_0 + P_1P_0C_0$）

### 数值比较器

输入两个二进制数 $A$ 和 $B$，判断它们的大小关系
通常有三个输出端，分别代表：

- $Y_{A>B}$ ($A$ 大于 $B$)
- $Y_{A<B}$ ($A$ 小于 $B$)
- $Y_{A=B}$ ($A$ 等于 $B$)

 1位比较器：

1. 相等 ($A=B$)：$Y_{A=B} = A \odot B = (A \oplus B)'$
2. 大于 ($A>B$)：Y_{A>B} = A \cdot B'$
3. 小于 ($A<B$)：$Y_{A<B} = A' \cdot B$

多位比较器（74HC85）：高位优先

引脚说明

- 数据输入：$A_3, A_2, A_1, A_0$ 和 $B_3, B_2, B_1, B_0$
- 功能输出：$Y_{A>B}, Y_{A<B}, Y_{A=B}$
- 级联输入：$I_{A>B}, I_{A<B}, I_{A=B}$

级联扩展

- 芯片内部逻辑通常是把低位芯片的输出，接到高位芯片的级联输入端
- 高位芯片：负责比较 $A_7 \sim A_4$ 和 $B_7 \sim B_4$
- 低位芯片：负责比较 $A_3 \sim A_0$ 和 $B_3 \sim B_0$
- 高位芯片先看自己的 4 位。如果分出胜负（比如高位 $A$ 大），直接输出结果，无视低位芯片的输入
- 如果高位芯片发现自己这 4 位完全相等，它就会去读级联输入（也就是低位芯片的判定结果），并把那个结果传出去

## 课时六 触发器

### 基本触发器类型

SR触发器： 

- S=1, R=0 -> 置1 

- S=0, R=1 -> 置0 

- S=0, R=0 -> 保持 

- S=1, R=1 -> 约束状态（禁止） 

- 特性方程：$Q^{n+1} = S + R'Q^n$ (约束条件 $SR=0$) 


JK触发器： 

- J=1, K=0 -> 置1 
- J=0, K=1 -> 置0 
- J=0, K=0 -> 保持 
- J=1, K=1 -> 翻转（次态与初态相反） 
- 特性方程：$Q^{n+1} = JQ^{n'} + K'Q^n$ 
- SD’和RD’是使能端，当SD’为1时，Q强制置1，当RD’为1时，Q强制置0

D触发器： 

- D=1 -> 置1 
- D=0 -> 置0 
- 特性方程：$Q^{n+1} = D$ 

T触发器： 

- T=1 -> 翻转 
- T=0 -> 保持 
- 特性方程：$Q^{n+1} = T \oplus Q^n = TQ^{n'} + T'Q^n$

### 触发方式

上升沿触发：CLK 引脚处画了一个小三角形

下降沿触发：小三角形前面加了一个圆圈

脉冲触发（主从触发）：（默认正脉冲。负脉冲加个圆圈）下降沿触发，但是取决于整个CLK置1期间，是否有一刻为1

电平触发：CLK为1的时间内才发生连续变化

## 课时七 时序逻辑电路

### 时序电路特点

电路中包含存储电路（触发器）

输出不仅取决于当前输入，还取决于电路原来的状态

时序逻辑电路具有记忆功能
存储单元：只能存储一位数据的电路
寄存器：用于存储一组数据的存储电路
存储器：用于存储大量数据的存储电路

### 时序逻辑电路分析步骤

1. 写出方程： 输出方程（Y = ...） 驱动方程（触发器输入 J=..., K=...）
2. 代入触发器特性方程，求出状态方程（Q(n+1) = ...）
3. 列出状态转换表
4. 画出状态转换图或时序波形图
5. 分析功能（如几进制计数器）



### 计数器

同步计数器：所有触发器受同一时钟脉冲控制

异步计数器：触发器的时钟脉冲不完全相同，通常前一级的输出作为后一级的时钟

74HC161**：**4位 二进制计数器 (模16，数 0~15)

74HC160：十进制 计数器 (模10，数 0~9，即 BCD 码)

引脚说明

1. CLK：时钟输入，通常是上升沿有效

2. $\bar{CR}$ 或 $\bar{MR}$ ：清零端

   - 低电平有效（给 0 就强制变 0000）
   - 异步清零 (如 74LS161)：只要 $\bar{CR}=0$，不管时钟咋样，立马清零
   - 同步清零 (如 74LS163)：$\bar{CR}=0$ 后，要等下一个时钟上升沿来了，才清零

3. $\bar{LD}$ 或 $\bar{PE}$：置数端 (预置)

   - 低电平有效
   - 当 $\bar{LD}=0$ 时，在时钟上升沿，把输入端 ($D_3 D_2 D_1 D_0$) 的数据“抄”到输出端

4. EP & ET：使能端

   - 通常有两个开关，必须全是 1，计数器才开始数数。
   - 用于多片级联（比如两片 161 连成一个 8位计数器）

5. RCO 或 TC：进位输出

   当计数器数到最大值（二进制的 15 或十进制的 9）时，这个脚会输出一个高电平脉冲

任意进制计数器设计： 

1. 置零法（复位法）：计数到N时产生复位信号
2. 置数法（置位法）：计数到N时产生置数信号装载初值

## 寄存器

**数码寄存器（并行寄存器）**

时钟到来时，将输入端口的 N 位数据全部记录下来，并一直保持输出，直到下一次时钟到来

结构：N 个 D 触发器，时钟线 (CLK) 和 清零端 (CLR) 连在一起

输入输出方式**：**并行输入，并行输出

应用：CPU 的数据暂存、IO 口的输出锁存（防止 LED 乱闪）

**移位寄存器**

所有的触发器串联起来（前一个的 Q 接后一个的 D）

每来一个时钟脉冲，数据就整体向左或向右移动一位

可用于：串/并行数据转换

四大工作模式：

1. 串入并出：节省IO
2. 并入串出
3. 串入串出：用于数据延时
4. 并入并出：带移位功能的普通寄存器
