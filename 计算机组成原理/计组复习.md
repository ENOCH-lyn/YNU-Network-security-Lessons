# 计算机组成原理复习

## 第一章：计算机概述 

### 冯·诺依曼机

- 五大部件：运算器、控制器、存储器、输入设备、输出设备
- 指令和数据同等地位存于存储器，按地址访问
- 以运算器为中心

### 计算

CPI ：执行一条指令需要的时钟周期数

MIPS：每秒执行多少百万条指令。公式：$\text{MIPS} = \frac{\text{主频}}{\text{CPI} \times 10^6}$ 2

程序执行时间：$T = \frac{\text{指令条数} \times \text{CPI}}{\text{主频}}$

## 第二章：数据的表示与运算

### 补码规则

符号位不变，数值位取反 +1

8位补码范围：$-128 \sim +127$

$-128$ 补码：`1000 0000` (无法转原码)

移位规则：

- 左移：一律补 0 (丢弃高位)

- 算术右移 (补码)：高位补符号位 (正补0，负补1)，低位丢弃

### 浮点数 (IEEE 754)

格式：$(-1)^s \times 1.M \times 2^{E-127}$

阶码：真值 + 127

加减运算：

1. 对阶：小阶看齐大阶
2. 尾数加减
3. 规格化：
   - 左规：尾数是 `0.00...`，左移，阶码减
   - 右规：双符号位出现 `01` 或 `10` (溢出)，右移 1 位，阶码 +1
4. 舍入 (0舍1入)
5. 溢出判断：阶码溢出才算真溢出

### 校验码

奇偶校验：检错 1 位，不能纠错
海明码：能纠错 

- $n$ ： 码字的总长度（包含信息位和冗余位）
- $k$： 信息位（数据位）的长度，即有效的原始数据位数
- $r$： 冗余位（也称校验位）的位数
- $$n = k + r$$
- $2^r \ge k + r + 1$

CRC (循环冗余校验)：模 2 除法，余数拼接在数据后

## 第三章：存储系统

### SRAM vs DRAM

| 特性       | SRAM (Cache)    | DRAM (内存)           |
| ---------- | --------------- | --------------------- |
| 存储元     | 触发器 (双稳态) | 电容 (电荷)           |
| 刷新       | 不需要          | 需要 (分散/集中/异步) |
| 速度       | 快              | 慢                    |
| 破坏性读出 | 否              | 是 (读后需重写)       |

其中DRAM 的三种刷新方式：

1. 集中刷新
   - 留出时间集中把所有行刷新一遍
   - 有死区
2. 分散刷新
   - 前半段读写，后半段刷新
   - 没有死区，但是整个存取周期变长了
3. 异步刷新
   - 结合前两者，把刷新任务平均分配到 2ms 内
   - 死区非常短

### 存储扩展计算

位扩展：增加字长 (如 1K×4位 $\rightarrow$ 1K×8位)，数据线并联

字扩展：增加容量 (如 1K×8位 $\rightarrow$ 2K×8位)，地址线高位做片选

### Cache 地址映射 

假设地址总长 $L$，Cache 行数 $2^c$，块大小 $2^b$ (Offset位数)

- 直接映射：
  - Offset = $b$
  - Index (行号) = $c$
  - Tag = $L - c - b$
- 全相联映射：
  - Offset = $b$
  - Tag = $L - b$ 
  - (没有 Index)
- 组相联映射 ($K$路)：
  - Offset = $b$
  - Index (组号) = $c - \log_2K$
  - Tag = $L - \text{Index} - b$

### Cache写操作策略

写命中 (Hit) 时：

1. 全写法：同时写 Cache 和 内存。（慢，但数据安全）
2. 回写法：只写 Cache，同时标记。等这块要被踢出去时，再写回内存。 （快）

写不命中 (Miss) 时：

1. 写分配：把那块从内存调入 Cache，再写。 （配合回写法）
2. 非写分配：直接写内存，不调入 Cache。 （配合全写法）

### Cache分配策略

- RAND：随机
- FIFO：先来先走
- LRU ：替换访存次数最少的

### 性能与虚拟内存

Cache 平均时间：$T_{avg} = h \cdot T_c + (1-h) \cdot T_m$

虚拟内存 (页式)：

- 转换：虚拟地址 (VPN + Offset) $\rightarrow$ 物理地址 (PFN + Offset)
- TLB：页表的 Cache，全相联，存的是 VPN
- Offset 永远不变

### 硬盘

总时间 = 寻道时间 +旋转延迟+ 传输时间
旋转延迟通常取旋转一周时间的一半（平均等待时间）

## 第四章：指令系统

### 常见寻址方式

- 立即 (`#2000`)：数就是 2000
- 直接 (`2000`)：数在 `Mem[2000]`
- 间接 (`(2000)`)：数在 `Mem[ Mem[2000] ]`
- 寄存器 (`R1`)：数在 `R1`
- 寄存器间接 (`(R1)`)：数在 `Mem[R1]`
- 相对 (`PC+Offset`)：跳转目标 = `PC_current + 1 + Offset`
- 隐含寻址

### 扩展操作码计算

公式：(上一层剩余坑位) $\times 2^{\text{地址位宽}} =$ 下一层最大指令数
原则：短操作码不能是长操作码的前缀

## 第五章：中央处理器 (CPU)

### 数据通路

#### 取指周期

1. `(PC) -> MAR`
2. `1 -> R` (读)
3. `M(MAR) -> MDR`
4. `MDR -> IR`
5. `(PC) + 1 -> PC`

取指周期：取决于`指令字长/存储字长`

#### 间址周期：拿真实地址

1. `Ad(IR) -> MAR`
2. `1 -> R` (读)
3. `M(MAR) -> MDR`
4. `MDR -> Ad(IR)` (替换掉旧地址)

#### 执行周期

取数 (LOAD X)

1. `Ad(IR) -> MAR`
2. `1 -> R`
3. `M(MAR) -> MDR`
4. `MDR -> ACC`

存数 (STORE X)

1. `Ad(IR) -> MAR`
2. `ACC -> MDR` 
3. `1 -> W` (写)
4. `MDR -> M(MAR)`

跳转 (JMP X)

1. `Ad(IR) -> PC`

中断周期

1. `SP -> MAR` (或特定地址)
2. `PC -> MDR` (存断点)
3. `1 -> W`
4. `MDR -> M(MAR)`
5. `Vector -> PC` (去中断服务程序)

### 控制器 (CU)

硬布线：速度快，RISC，电路难改

微程序：速度慢，CISC，存微指令 (修改 ROM 即可)

微指令编码：

- 字段编码：每组互斥信号留一个 NOP
- 位数 = $\sum \lceil \log_2(\text{每组信号数}+1) \rceil$

微指令长 `K` 位，包含 操作控制字段 和 顺序控制字段
操作控制字段：直接编码，垂直/分组编码
顺序控制字段：`[ 判别测试位 (P) ] [ 直接地址 (AD) ]`

### 流水线

周期 $\Delta t$ = 最慢的一段

总时间 = $(k + n - 1) \times \Delta t$
- $k$: 阶段数
- $n$: 指令条数

加速比 $S = \text{串行总时间} / \text{流水线总时间}$

### 各种周期的区分

指令周期：CPU 取出并执行完一条机器指令（如 `MOV`, `ADD`）所需的全部时间

机器周期=CPU 周期=微指令周期：CPU 访问一次内存所需的时间

T 周期 / 时钟周期：主频的倒数

总线周期：总线进行一次数据传输（如 CPU 读一次内存）的时间

## 第六章：总线与 I/O

### 总线带宽

公式：$\text{带宽} = \text{总线位宽 (bit)} \times (\text{总线频率} / \text{每传一次的时钟周期数}) / 8$

注意单位换算：Bit 转 Byte 要除以 8

### I/O 方式对比

| 方式     | CPU 状态                  | 数据搬运者       | 适用场景            |
| -------- | ------------------------- | ---------------- | ------------------- |
| 程序查询 | 忙等 (串行)               | CPU              | 极慢设备            |
| 中断     | 暂停现行程序 (并行)       | CPU (软件 ISR)   | 键盘、鼠标 (低速)   |
| DMA      | 仅暂停一个存取周期 (并行) | DMA控制器 (硬件) | 硬盘、显卡 (块传输) |

### 中断处理流程

- 硬件 (中断隐指令)：关中断、保存 PC、引出程序
- 软件：保存现场 (寄存器)、服务、恢复现场、开中断、返回

### 三种总线

系统总线 (System Bus) 连接 CPU、内存和 I/O 接口，包含三组线：

1. 数据总线 DB (Data Bus)

   - 功能：传输“内容”（指令、数据、中断类型号）
   - 方向：双向（CPU $\leftrightarrow$ 内存/IO）
   - 宽度：决定了性能（一次能搬多少砖）。通常与机器字长一致（如 32位、64位）

2. 地址总线 AB (Address Bus)

   - 功能：指明“去哪里”（内存单元或 I/O 端口的地址）

   - 方向：单向（CPU $\rightarrow$ 外部）

   - 宽度：决定了最大寻址能力（能找多少个门牌号）

     公式：若 AB 宽度为 $n$，寻址范围 $2^n$

3. 控制总线 CB (Control Bus)

   - 功能：指挥交通（读写命令、中断请求、总线允许）
   - 方向：混合（有的出 CPU，如 `Write`；有的进 CPU，如 `Interrupt`）

### 仲裁方式

| 仲裁方式   | 判优依据            | 优点         | 缺点                   | 控制线根数 (考点)            |
| ---------- | ------------------- | ------------ | ---------------------- | ---------------------------- |
| 链式查询   | 物理位置 (靠前优先) | 简单、线少   | 坏一个全死、优先级死板 | 3 (最少)                     |
| 计数器查询 | 计数器数值          | 优先级可编程 | 稍微慢点               | $\lceil \log_2 N \rceil + 2$ |
| 独立请求   | 内部排队电路        | 响应最快     | 硬件复杂、线多         | $2N + 1$ (最多)              |

### 总线通信控制方式

| 比较维度 | 同步通信            | 半同步通信                 | 异步通信                 | 分离式通信                 |
| -------- | ------------------- | -------------------------- | ------------------------ | -------------------------- |
| 核心特点 | 统一时钟，强制同步  | 统一时钟 + 握手 (WAIT信号) | 无时钟，全靠握手 (应答)  | 释放总线，传输分两个子周期 |
| 时钟信号 | 必须有公共时钟      | 必须有公共时钟             | 无需公共时钟             | 通常基于同步时钟           |
| 握手信号 | 无 (默认对方能跟上) | 有 (WAIT/READY 信号)       | 有 (请求 REQ / 确认 ACK) | 依靠逻辑编号或标签匹配     |
| 传输速度 | 最快 (无握手开销)   | 较快 (允许插入等待)        | 较慢 (握手一来一回耗时)  | 总线利用率最高 (宏观上快)  |
